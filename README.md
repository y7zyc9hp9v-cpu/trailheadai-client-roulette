# Trailheadai Fake Client Roulette

A small offline practice toy for spinning up pretend Wisconsin small-business sample sites. It is one HTML file with a reusable layout: press **Spin a client** (or **Spin again**) to swap in a new made-up business.

## How to open

On the box, open this file in a browser:

`/workspace/trailheadai-client-roulette/index.html`

It works without internet. Double-click it in a file browser, or paste the path into the browser's address bar.

## What is included

There are 10 fictional Wisconsin businesses covering auto detailing, plumbing, bait and tackle, lawn care, salon, bakery, auto glass, snow plowing, pet grooming, and HVAC. Each has a town vibe, tagline, three service cards, and clearly fake demo contact details.

## Walls

- **SAMPLE DEMO / DEMO ONLY** is intentionally visible on every view.
- No real clients, calls, emails, payments, Cash App links, forms, or selling flows.
- Do not treat the names, numbers, or sample copy as real businesses.
- This is a local practice page only; it does not touch the live Trailheadai site or any live repository.
